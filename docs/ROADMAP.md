Detaljerede opgaver findes i `docs/TASKS.md`.

Mål:

- forstå problemet
- definere MVP
- vælge stack

Exit criteria:

- PRD er implementeringsklar
- væsentlige teknologivalg er dokumenteret
- første milestone er opdelt i tasks
